# Hive AI - Identidade Visual Elegante

## 🎨 Paleta de Cores
- **Primary (Deep Indigo)**: #1A237E (Seriedade, Profundidade, Tecnologia).
- **Accent (Amber)**: #FFC107 (Energia, Inteligência, Creatividade).
- **Background**: #F5F5F7 (Limpo, Moderno, Apple-like).
- **Surface**: #FFFFFF (Branco puro para cartões e bolhas).

## 🖋 Tipografia
- **Font-family**: 'Inter', sans-serif (Preferencialmente).
- **Headings**: Semi-bold, cor Deep Indigo.
- **Body**: Regular, legibilidade maximizada.

## 💬 Layout de Chat
- **Alinhamento**: Centralizado (max-width: 850px).
- **Mensagens**:
    - **Bolhas**: Bordas arredondadas assimétricas (ex: 18px top/left/right, 4px bottom-left para agente).
    - **Espaçamento**: Generoso entre as mensagens para evitar fadiga visual.
- **Shadows**: Soft shadows (0 4px 6px rgba(0,0,0,0.05)) para profundidade.

## ✨ Elementos de Interface
- **Botões**: Arredondados, com hover states em Amber.
- **Inputs**: Minimalistas, focados no prompt.
- **Animations**: Transições suaves (fade-in-up) para novas mensagens.
